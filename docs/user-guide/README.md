# XNAT Workstation — User Guide

> **Draft.** Chapters 1–4 and the glossary are written; the rest are outlined below and
> still to come. Every chapter opens with a *Draft status* note listing what has not yet been
> checked against the running app. Do not publish until those lists are empty.

This guide is for image reviewers and annotators — radiologists, technologists, research
assistants, imaging scientists — who already know their way around medical images (window and
level, planes, series, some DICOM) and have annotated in another tool, but who may be new to
**XNAT** and are certainly new to **XNAT Workstation**.

It is task-first: each chapter starts from something you want to do. Terms the app uses in a
particular way (*container*, *member*, *viewport*…) are in **bold** the first time and defined
in the [Glossary](glossary.md).

## Conventions in this guide

- **Bold** names a control exactly as it appears on screen: **Sign In with XNAT**, **Import**.
- `›` is a path through menus or settings: **Settings › Updates**.
- ⌘ is the macOS Command key; on Windows and Linux use Ctrl where the guide says ⌘.
- Notes marked *Draft status* are for the people writing and checking this guide, and are
  removed before release.
