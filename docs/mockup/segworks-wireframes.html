Sheet rules

  • Header: back arrow (to the Process list) · operation name · target member chip in its own colour. Targets come from the panel's active member, so there is no target dropdown. Exception: two-segment ops (Move/Merge/Magnet bridge) add a second “into” selector.
  • Advanced is collapsed by default and remembers its state per operation. Algorithm variants (all ported, per decision 5) are a single dropdown, never separate operations.
  • Locked members: Commit is disabled with the existing lock explanation; Preview still works (read-only).
  • Progress is inline in the sheet and mirrored in the viewport status overlay with Cancel. No toast for progress or success (no-banner rule). A toast is used only for partial failure.
  • Memory guard (Graph Cut, α-Exp, Chan-Vese): an estimate line, then an amber warning, then a disabled Run with a reason. Never a modal.
  • Leaving the sheet with an uncommitted preview leads to an inline “Discard preview?” confirm in the sheet, not a dialog.

15 · D12 — Hotkeys

SegWorks' keys collide with Workstation's: A (angle vs anchor A), B (brush vs anchor B), C (crosshairs vs correction), F (paint fill vs freehand), S (stack scroll vs fill holes), W (W/L vs hold-erase), L (length vs lung mode). All keys remain remappable in Settings › Hotkeys.

D12How operation-specific keys coexist with the global map

A · Sheet-scoped keys recommended

While a sheet is open, a small sheet keymap takes precedence over the global map, and the sheet shows its keys inline (e.g. Interpolate: A/B set anchors, ⇧A/⇧B clear, ⇧C clear both). Closing the sheet restores the global meaning. This is the same mechanism as the existing name-capture handler.

Keeps SegWorks muscle memory where it matters without taking away global keys

The same key means different things depending on context, so the sheet must show its keys

B · Global, unique keys only (e.g. Alt+A / Alt+B)

One meaning per key

Chords for frequent anchor work; Alt+letter is awkward on macOS
